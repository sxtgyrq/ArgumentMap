LN6 的 logic 修改时，关联 LN4 在同一事务内同步为新 P／¬P，保留 True／False；删除 LN6（含框选删除）时，仅清空关联 LN4.logic，保留其值。移动不属于新增，不会重新编号。导入属于新增：LN4 优先匹配本批输入中完整 logic 原文相同的唯一 LN6；该源自动加序号时，本批 LN4 的对应引用同步，已有 LN4 保持原关联。本批没有同名源时，按最终地图校验对应唯一 LN6；本批多个同名 LN6 存在分支引用时返回 AmbiguousBranchSource，整批拒绝。False 的逻辑语言包含 ¬ 前缀，其对应 LN6 完整 logic 最多 254 字符，组合后最多 255；True 的对应源最多 255。复合命题需整体否定时，LN6 自身可写 (A ∧ B)，False 写 ¬(A ∧ B)，软件不会自动添加括号或化简。

LN8（size 8）只能使用 value="="（等同）、value="→"（蕴含）、value="↔"（等价）、value="¬"（非／NOT）、value="⊇"（包含）、value="⊋"（真包含）、value="⊆"（包含于）或 value="⊊"（真包含于），八种符号均可重复，全图不设 LN8 数量上限。logic 自动生成：¬ 对应 ¬(?)，其他符号与 value 完全一致，允许重复。? 表示尚未指定的输入命题。手工新增和编辑由 Server 自动同步；导入漏填或空串自动补齐，旧 ¬ 自动规范为 ¬(?)，其他不一致或 null 拒绝整批；不可另填关系表达式，补充含义写 info。绘图约定：= 连接两个 LN12 所指对象/概念；→ 连接两个 LN6，按前提到结论排列；↔ 连接两个 LN6 表示逻辑等价，P↔Q 等效于 (P→Q)∧(Q→P)，R↔(P∧Q) 可定义复合命题。¬ 是一元非（NOT）：按输入 LN6 P → LN8 ¬ → 输出 LN6 Q 绘制，含义为 Q ↔ ¬P，P 是唯一输入、Q 是结果；value 为 ¬，logic 固定为 ¬(?)，不接受 ¬(P) 等具体操作数，不接受 NOT、!、非或带空格的变体，不把 P¬Q 当成二元关系。集合关系用于 LN12，按左 A 右 B 读取：A⊇B 为 A 包含 B，A⊋B 为 A 真包含 B，A⊆B 为 A 包含于 B，A⊊B 为 A 真包含于 B；⊇/⊆ 允许相等，⊋/⊊ 必须不等。不要用 ⊃/⊂ 替代，不把 LN10 的 ∈ 当成 LN8 值。像 LN6 一样自由放置，不自动检查两端类型，也不执行逻辑或改变 Cross 通行。青色倒角方形的四角各切去两条直角边为 0.5 的等腰直角三角形；几何仍按完整 8×8 外接正方形校验。每批导入上限仍为 256 个 LN，不是全图数量上限。不要添加端点选择、绑定字段或额外模型。
